# 兼容性与功能边界

基准：DLT v1 的常见二进制交换结构，范围对照 AUTOSAR R19-11；本项目没有获得 AUTOSAR 一致性认证。`pydlt==0.3.5` 基于更早的 R4.0 Rev3 常用格式，只能为双方共有子集提供独立互操作证据。

| 能力 | 当前承诺 |
| --- | --- |
| 版本 | v1；拒绝把 v2 当作 v1 解码 |
| 封装 | Storage (`DLT\x01`)、显式 Network、Serial (`DLS\x01`) |
| 标准头 | 所有 ECU/session/timestamp/extended 可选字段组合 |
| 字节序 | 头数值网络序、Storage 时间小端、载荷按 MSBF 双字节序 |
| 标识符 | 0–4 字节可打印 ASCII、右侧零填充；比允许任意原始标识字节的实现更严格 |
| 常用 verbose | bool；i/u8/16/32/64；f32/f64；ASCII/UTF-8；raw |
| 高级 verbose | 独立 `parameters()` API：VARI ASCII 名称/单位、FIXP 整数缩放、同类 bool/整数/浮点数组；维度 1–16，每维 1–65,535，总数受消息预算约束 |
| JSON 参数交换 | 整数十进制字符串、浮点 IEEE 位模式、文本编码、raw 十六进制及高级元数据；不把 64 位整数降为 JS Number |
| 消息 JSON | `moondlt.message.v1` 保留头和原始 payload_hex，未知类型和 NaN 载荷位不经过参数转换 |
| nonverbose | 保留原载荷；按应用显式注册的固定布局解码与编码 |
| 分片 | 字节级任意分片，缓存受调用者预算约束 |
| 恢复 | Storage/Serial 的有界重新同步；显式记录跳过量；Network 禁用 |
| 时间 | Storage 的 Unix 秒和微秒、头部 ECU uptime tick 均保留；不自动校时 |
| 查询 | 内存头索引、字段/等级/存储时间过滤、原字节提取与重新封装 |
| 表达式 | 有界的头字段比较、`!`、`&&`、`||` 和括号；不执行脚本或载荷正则 |
| 大型输入 | `Source` 的 UInt64 偏移、精确 `read_at` 回调、只读头遍历、选中记录读取与窗口缓存；回调对应数据必须保持稳定 |
| 侧目录 | 严格 JSON 结构与连续区间检查；默认 `open` 核验采样标识和所有记录头；显式 `open_trusted` 仅适用于调用者已验证的可信目录 |
| 连续性 | 按 ECU/应用/上下文观察计数器与时间戳变化；缺失计数值不是已经证实的网络丢包数 |
| 控制载荷 | 常用 v1 服务请求、通用响应与软件版本载荷；不执行设备操作、不含完整会话状态机 |

当前不覆盖：DLT v2、完整 FIBEX/XML、厂商私有协议自动推断、128 位数值、f16、结构体与 trace-info 参数、完整任意嵌套类型体系、车辆硬件访问、daemon、TCP/UDP 重连、认证、UDS、CAN 信号解码。高级 verbose 的范围以生成接口和相应测试为准，不能由常用标量的互操作结果推断高级类型已与外部库互通。

载荷保留不等于载荷语义已被解析。基本记录解析成功后，若调用不支持类型的解释函数，仍可能返回 `Unsupported`。读取器拒绝非法长度、超预算、非终止字符串、错误计数等输入，不尝试替厂商修复所有不规范日志。

高级 VARI 元数据遵循 ASCII 约束；数值标量和所有数组含名称及单位字段，布尔/字符串/raw 标量只含名称。固定点保留整数原始值、binary32 量化系数和有符号偏移；`logical_values()` 会产生近似的 Double 物理值。f32 参数在类型模型中转换为 Double，可能静默化 signaling NaN；不保证重编码维持所有 NaN 载荷位。原始 `Message.payload` 的复制不经过此数值转换，可保持原字节。

UTF-8 编码入口会先校验 UTF-16 代理项及字节预算；非法代理项统一返回 `DltError`。`logical_values()` 校验完整参数结构，并按实际 binary32 精度解释 f32。构造 verbose 消息时预算涵盖完整消息头和载荷，而非只检查载荷长度。连续性模块跨过缺失可选字段时保留最后已知基线，不把字段缺省解释成已经重启。

`Limits::default()` 的当前默认值：消息长度 65,535 字节、输入块加 pending 262,144 字节、最多 255 个参数、字符串 65,535 字节、连续恢复扫描 1,048,576 字节。接口允许自定义，但配置本身也经过检查。

侧目录的源标识只采样头尾并采用非密码学散列，用于发现误用过期文件，不能认证文件、目录或未采样载荷。默认 `SourceCatalog::open` 还会完整扫描并比较所有记录元数据；不读取并认证全部载荷。`open_trusted` 跳过逐头比较，篡改的目录可能让过滤遗漏记录，不应给不可信侧文件使用。两种方式都要求宿主在读取期间保持源稳定。

## 互操作证据的适用范围

54 个黄金向量覆盖 18 组消息定义与三种封装。Serial 的 4 字节标记由宿主验证和剥离后交给 pydlt 的 Network 解析器；pydlt 并没有被声称为 Serial 层的完整实现。向量比较的是完整字节和类型值，不包含实际车载网络、量产日志全库或官方认证测试集。
